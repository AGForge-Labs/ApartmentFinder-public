# ApartmentFinder

Local-first apartment navigation and delivery planning. The app includes a reviewed public apartment catalog, source-qualified approximate unit positions, and public map geometry for offline use. Missing buildings, units and exact doors remain explicit gaps.

Personal pin corrections, notes, paths, manifests, delivery progress and backups stay in the existing on-device store. Optional private map packs remain supported. A public catalog update adds compatible missing source data without rewriting personal records or installed private generations.

See [catalog scope and safeguards](docs/public-catalog.md), [optional private packs](docs/private-packs.md), and [validation boundaries](docs/testing.md). Simulator compatibility, installed-phone upgrade acceptance and signed TestFlight distribution are separate gates.

The proposed manual public build/sign/upload route and its required credential protection are documented in [public release preparation](docs/public-release.md). Activation and a signed public-source release remain pending.
