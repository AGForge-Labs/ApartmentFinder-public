# ApartmentFinder

Local-first apartment navigation and delivery planning. Production identities and personal storage are retained. Complete private map packs are imported on the device; personal backups remain separate.

This public repository contains source, a public address index and synthetic regression inputs. Real catalogs, pin corrections, route data, gate codes, credentials and owner exports must stay private. Native compatibility and installed-upgrade acceptance are separate release gates. See [private pack installation](docs/private-packs.md) and [validation](docs/testing.md).
