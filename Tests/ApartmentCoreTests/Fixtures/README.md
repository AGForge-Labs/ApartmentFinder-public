These are invented regression fixtures, generated by
`python scripts/generate-manifest-fixtures.py`. No owner export is an input.

`1200 Fictional Courtyard Way`, units 4102/4108, the fictional courtyard IDs,
and the matching test coordinates are invented. Las Vegas/NV/89113 are retained
only as public locality tokens for the existing CSV grammar. Stop 44 is a
regression label shared by separate invented packages.

The valid archive contains one two-row day and one header-only day. Rejection
variants deliberately contain a bad CRC, a traversal path, an encryption flag,
an expanded member exceeding 5 MB, and ZIP64 size/descriptor metadata overflow.
ZIP timestamps, entry order, permissions and compression settings are fixed.
The script also updates the existing simulator manifest's embedded archive.

Core, native and UI tests keep import, separate contacts, printed labels, source
pins, backup/reopen, unknown-door, undo, cancellation and share assertions. The
UI fixture is installed only through the explicit DEBUG test controls with an
isolated test store. Real directory acceptance continues to require the separate
private inputs; these fictional tests do not qualify real map data.
