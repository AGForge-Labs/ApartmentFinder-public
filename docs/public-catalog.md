# Public apartment catalog

## Published boundary

The public bundle contains property identities and physical street addresses, traceable public evidence sources, qualified property-reference coordinates, source-mapped or estimated building/unit positions, and unconfirmed public OpenStreetMap paths. It contains no exact or field-verified doors.

It excludes gate/access codes, resident/customer information, manifests, package identifiers, personal notes, phone exports, recorded personal routes, credentials and private source history. Public availability of a page does not establish current accuracy or redistribution rights. No copyrighted map artwork is bundled. Retained OSM geometry requires OpenStreetMap contributors attribution and ODbL compliance.

`public-catalog.json`, `public-locations.geojson`, `public-paths.geojson` and `known-addresses.json` are generated by the field allowlist in `scripts/public-catalog.py`. `public-catalog-review.json` records the reviewed resource digests and counts. Publication must include only the approved projection, never an unreviewed source pack or personal backup.

Inherited free-text notes are replaced by fixed precision/incompleteness warnings, except for exact reviewed directory/area cohorts whose complete feature and source SHA-256 seals preserve their published qualifications. Revision `2026.10.19.2-public` also retains fixed, source-shape-checked safety qualifications: building A is not asserted for 7380 Russell unit 201; 6350 Riley has county ZIP 89113 and an independently unverified retained postal ZIP 89148; retained 6355 Riley positions lie in county ZIP 89148. The two existing unmatched Riley labels keep their additional caution. No arbitrary raw notes are copied. Uncertainty and source confidence remain explicit. Source pin coordinates, labels and IDs are retained except for the existing fingerprint-checked Riley street separation. The original source is validated separately from this smaller public projection; stripped derivation metadata cannot be claimed to satisfy the old deep private-provenance checks.

## Existing installations

The app reads the existing selected private generation or legacy seed first. The public bundle supplies a fresh-install fallback and an in-memory supplement of compatible missing communities, positions and unconfirmed paths. Existing source IDs, physical identities, saved point coordinates and private paths take precedence. Conflicting public additions are excluded instead of rebinding existing data.

No public generation is silently installed over the selected private pack. Personal records retain their separate storage and override priority. Loading a public catalog performs no hidden personal-data write. An explicitly saved path at a public-only community captures its selected street identity atomically with the path; existing explicit rules are not overwritten. Unknown legacy path ownership remains protected. Mini-route receipt evidence uses the exact saved stop identities, preserving completion and Undo.

The Share extension reads a union of its bundled public street index and any valid installed private snapshot. New public streets are therefore available before the main app first launches; the extension does not rewrite the selected snapshot.
