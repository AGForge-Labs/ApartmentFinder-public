# Optional private map packs

The app includes its reviewed public catalog, so normal first use does not require a private-pack import. Use Import private map pack for an additional complete custom pack containing catalog.json, locations.geojson and paths.geojson from the same generation.

All files are validated before activation. Existing personal pins, stops, paths, notes and backups remain separate. Existing source-map identities and compatible public additions are retained without rewriting the private generation.

Keep private source packs and backups outside this source tree. Existing app data and previous pack generations are preserved. iOS file protection provides the existing device storage boundary; this change does not create a portable encrypted backup or upload personal data.
