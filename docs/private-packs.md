# Private map packs

Use Import private map pack to select a folder containing catalog.json, locations.geojson and paths.geojson from the same complete pack. All files are validated before activation. Existing personal pins, stops, paths and backups remain separate.

Keep private source packs and backups outside this source tree. Existing app data and previous pack generations are preserved. iOS file protection provides the existing device storage boundary; this change does not create a portable encrypted backup.
